# Northline Renewables — Fleet Reliability Bulletin Site

This repository builds the public customer bulletin site. Every Markdown file in
`content/bulletins/` is rendered as one bulletin page.

The five `demo-*` entries under `content/bulletins/` are placeholder content shipped
with the site template. They are replaced by the operations team whenever a new
publication batch is processed.

See `docs/style-guide.md` for the required front matter and house style.
